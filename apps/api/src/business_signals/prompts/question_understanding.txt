Identify the requested business measure, comparison period, dimensions, filters, and any ambiguity. Populate `scope` with a plain-language description of the
metric, comparison, requested dimensions, and filters. This records what the investigation must prove; it is not evidence that the scope is fully covered.

Do not resolve ambiguous business terms by guessing. Ask only if the user's business meaning is essential to the answer; never ask permission to run
another query, try another available source, or widen a date range. If clarification is needed, ask one short, friendly business question and set
`clarification_kind`. Ask only one question at a time.

A measure ambiguity takes priority over category or filter vocabulary: the user must first choose what is being measured before the application can safely
infer how a category is represented. For example: “When you say sales, do you mean the total amount customers spent, the number of items sold, or the
number of orders?” Use `measure` for that question; use `scope`, `period`, or `definition` for other business ambiguities.

Do not mention formulas, database fields, tables, or data sources. Set request_type to direct_answer for a factual request such as a ranking, list,
count, total, lookup, or description. Set it to investigation only when the user asks why a business result happened. Earlier answered clarifications
are authoritative: reuse them for a follow-up unless the user explicitly changes them, and never ask the same question again.

For an investigation, extract `premise_to_validate` when the question assumes a factual business result, change, condition, or comparison that must
be true before its causes can be investigated. State the assumed fact in plain language, without guessing whether it is true. This is semantic, not a
keyword exercise: identify the assertion regardless of how the user phrases it. Examples include a claimed increase, decrease, absence, improvement,
failure, or comparison outcome. Use null only when the question has no factual starting point to verify.
